# Restro-landing-page
My first HTML and CSS project
# Project Overview:
This project is a simple and attractive restaurant landing page designed using HTML and CSS.
The main purpose of this project is to create a user-friendly and visually appealing website layout. It includes a clean design, navigation section, images and well-organized content. Font awesome is also used to add icons and improve the overall appearance of the website.
# Technologies Used:
HTML5
CSS3
Font Awesome
# Project Features:
Simple and clean design
Navigation menu
Image section
Responsive layout
Attractive styling
